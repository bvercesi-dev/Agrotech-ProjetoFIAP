# 🌱 AGROTECH - Olhinho na Planta
*Keeping an Eye on the Plants*

**Tecnologia para cuidar de hortas urbanas, acompanhar o solo e a compostagem e apoiar um cultivo mais sustentável.**  
*Technology to care for urban gardens, monitor soil and composting, and support more sustainable growing practices.*

O **Olhinho na Planta** é um projeto acadêmico desenvolvido no curso de Engenharia de Software.  
***Olhinho na Planta** is an academic project developed as part of a Software Engineering degree.*

Sua proposta é criar uma plataforma de inteligência ambiental para auxiliar os responsáveis por hortas urbanas e comunitárias no acompanhamento de dados e na tomada de decisões.  
*It aims to create an environmental intelligence platform to help urban and community garden managers monitor data and make informed decisions.*

## 🎯 Objetivo
*Objective*

Facilitar o monitoramento da umidade do solo, da temperatura da composteira e da massa de resíduos orgânicos, reunindo informações que possam apoiar o uso consciente da água e o reaproveitamento de matéria orgânica.  
*To simplify the monitoring of soil moisture, compost bin temperature, and organic waste mass, bringing together information that can support responsible water use and the reuse of organic matter.*

O projeto se conecta ao **Objetivo de Desenvolvimento Sustentável 2 da ONU: Fome Zero e Agricultura Sustentável**, com foco no fortalecimento da agricultura urbana.  
*The project aligns with the **United Nations Sustainable Development Goal 2: Zero Hunger**, with a focus on strengthening urban agriculture.*

## 🌿 Funcionalidades previstas para a plataforma
*Planned platform features*

- Monitoramento da umidade do solo.  
  *Soil moisture monitoring.*

- Acompanhamento da temperatura da composteira.  
  *Compost bin temperature monitoring.*

- Registro da massa de resíduos orgânicos.  
  *Recording of organic waste mass.*

- Histórico de leituras ambientais.  
  *Historical environmental readings.*

- Alertas para apoiar o acompanhamento da irrigação.  
  *Alerts to support irrigation monitoring.*

Os parâmetros utilizados nas simulações são demonstrativos e precisam de validação técnica antes de uma aplicação real.  
*The parameters used in the simulations are for demonstration purposes and require technical validation before real-world use.*

A temperatura da composteira, isoladamente, não confirma a maturação do composto.  
*Compost bin temperature alone does not confirm compost maturity.*

## 🚀 Como visualizar
*How to view the website*

1. Baixe ou clone este repositório.  
   *Download or clone this repository.*

2. Abra a pasta do projeto no Visual Studio Code.  
   *Open the project folder in Visual Studio Code.*

3. Abra o arquivo `index.html` com a extensão **Live Server**.  
   *Open the `index.html` file using the **Live Server** extension.*

4. Navegue pelas páginas utilizando o menu do site.  
   *Use the website menu to navigate between pages.*

A versão que utiliza o Tailwind via CDN precisa de conexão com a internet para carregar a estilização.  
*The version that uses Tailwind through a CDN requires an internet connection to load its styles.*

O vídeo incorporado também depende de conexão.  
*The embedded video also requires an internet connection.*
